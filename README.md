## Что смотреть в отдельных репозиториях

В папках лежат копии файлов. Две лабы надо смотреть в их собственных репозиториях, потому что там важны не только файлы:

- **Лаба 5.** История веток, конфликт и Pull Request есть только в [lab5-git-conflicts](https://github.com/qqZeR002/lab5-git-conflicts): [граф коммитов](https://github.com/qqZeR002/lab5-git-conflicts/network), [Pull Request с конфликтом](https://github.com/qqZeR002/lab5-git-conflicts/pull/1).
- **Лаба 6.** Пайплайн работает в [lab6-cicd-pipeline](https://github.com/qqZeR002/lab6-cicd-pipeline): [прогоны Actions](https://github.com/qqZeR002/lab6-cicd-pipeline/actions), [опубликованный сайт](https://qqzer002.github.io/lab6-cicd-pipeline/). В папке `lab6` этого репозитория файл пайплайна лежит как копия и не запускается.

В лабе 4 шаги red → green → refactor видны по коммитам в [lab4-unit-bdd](https://github.com/qqZeR002/lab4-unit-bdd/commits/main), в лабе 9 итерации работы — в [lab9-ai-tools](https://github.com/qqZeR002/lab9-ai-tools/commits/main).
