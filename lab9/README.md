## Как работает правило

Баг — словарь с полями `priority`, `status`, `updated_at`. Флаг ставится, если одновременно:

1. приоритет `critical`;
2. статус не `verified` и не `closed` (работа ещё не закончена);
3. с последнего обновления прошло **N суток или больше** (ровно N — уже флаг).

N задаётся параметром `sla_days`, по умолчанию 3. Текущее время тоже передаётся параметром `now`.

Сломанные данные не пропускаются молча, а дают ошибку:

| Что не так | Ошибка |
|-----------|--------|
| у бага нет поля `priority`, `status` или `updated_at` | `KeyError` |
| неизвестный приоритет или статус (например, `Critical`, `wontfix`) | `ValueError` |
| время без часового пояса | `ValueError` |
| время не `datetime` (строка, число, `None`) | `TypeError` |
| N не целое число больше 0 | `ValueError` |

Перед сравнением оба времени переводятся в UTC, поэтому перевод часов на летнее и зимнее время на результат не влияет.

```python
from datetime import datetime, timezone
from sla import flag_bugs

flagged = flag_bugs(bugs, now=datetime.now(timezone.utc), sla_days=3)
```

Вывод `python main.py`:

```
  [FLAG] #5 Не проходит оплата на iOS (fixed, 3 дн. без обновления)
```

Баг №2 без флага, потому что обновлялся вчера, №3 закрыт, №4 не критичный.

Тесты на границу N: ровно N суток (флаг), на секунду меньше (нет флага), на секунду больше (флаг), то же для N = 1, 2, 7, 30. Отдельно проверен N = 1 в часах: час назад, 12 часов, 23:59:59, ровно 24 часа. Время в тестах фиксированное (`NOW = 2026-11-13 12:00 UTC`), поэтому результат не зависит от момента запуска.

### Риски

**Практические**

- **Уверенный неверный код.** Черновик выглядел законченным и имел докстринг, но ошибался на границе. Без теста на ровно N дней это ушло бы в работу.
- **Тесты от того же ИИ, что и код.** Они могут повторять те же заблуждения. Поэтому поведение на границе я определил сам, а не взял из кода.
- **Ревью от того же ИИ тоже неполное.** 34 зелёных теста и готовый отчёт выглядели как конец работы, но повторная проверка нашла ещё четыре проблемы. Один проход ревью нельзя считать окончательным.
- **Галлюцинации API.** В этой работе не встретились, потому что используется только стандартная библиотека. Проверка простая: код запускается, а не просто читается.
- **Зависимость от формулировки.** «Без обновления N дней» ИИ сначала понял как «больше N». От одного слова в промпте меняется поведение на границе.
- **Режим агента.** Агент выполняет команды на компьютере. Установку программ и удаление файлов я разрешаю только явным подтверждением.

**Этические**

- **Утечка данных.** В промпты попадает всё, что видит агент. В этом проекте нет персональных данных и секретов: баги в примерах выдуманные.
- **Лицензии.** ИИ может воспроизвести чужой код. Здесь код короткий, на стандартной библиотеке, заимствований нет.
- **Авторство.** Основной объём кода написан ИИ. Я указываю это прямо, а не выдаю весь код за написанный вручную.
- **Ответственность.** За результат отвечаю я, а не модель, поэтому нужно понимать каждую строку и уметь её объяснить.
