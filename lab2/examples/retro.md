# Ретроспектива спринта 1

Формат «Что было хорошо / Что мешало / Что пробуем». 1 час, ведёт Дмитрий (Scrum Master).

## Что было хорошо
- Цель спринта выполнена: баг можно завести, сменить статус и закрыть.
- Тесты на смену статусов (TDD) поймали ошибку при доработке T-06.

## Что мешало
- Задачи по 2–3 дня ждали тестирования (Мария одна).
- Дефект T-12 нашли на 4-й день, но исправили только в спринте 2. Студия жаловалась на дубли.

## Что пробуем в спринте 2
- [ ] Разработчики сами проверяют задачи друг друга по чек-листу (коллективное владение).
- [ ] Для Critical-дефектов добавить дорожку «срочно», как Expedite в Kanban.
- [ ] Выкладывать на тестовый сервер каждую пятницу (Small Releases).

## Чек-лист для любой ретро
- [ ] Посмотрели burndown и velocity
- [ ] Каждый сказал хотя бы одно «мешало»
- [ ] Не больше 3 действий на следующий спринт
- [ ] У каждого действия есть ответственный
