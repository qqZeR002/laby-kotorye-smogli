## Обзор проекта

Небольшая студия мобильных игр ведёт баги в чате и таблице, и они теряются. Трекер багов — это сервис с REST API, где баг можно завести, назначить исполнителю, провести по статусам от `open` до `closed` и найти по фильтрам.

В репозитории лежит документация и stub-реализация API (данные хранятся в памяти). Stub нужен, чтобы запросы из документации можно было попробовать.

## Как посмотреть спецификацию

**Способ 1, без установки.** Открыть https://editor.swagger.io и вставить содержимое `openapi.yaml` (File → Import file).

**Способ 2, со stub-сервером.** Здесь запросы можно выполнять прямо из браузера кнопкой «Try it out».

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r src/requirements.txt
python src/app.py
```

Потом открыть http://127.0.0.1:8000/docs

## Операции API (кратко)

| Метод и путь | Что делает |
|--------------|------------|
| `GET /issues` | список багов, фильтры `priority` и `status` |
| `POST /issues` | завести баг |
| `GET /issues/{issueId}` | получить один баг |
| `PUT /issues/{issueId}` | изменить баг |
| `DELETE /issues/{issueId}` | удалить баг |
| `PATCH /issues/{issueId}/status` | сменить статус |

## Проверка спецификации

Спецификацию проверял пакетом `openapi-spec-validator`:

```bash
pip install openapi-spec-validator
openapi-spec-validator openapi.yaml
```
