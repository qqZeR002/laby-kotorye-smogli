# Задача 19: Голосование

**Студент:** Ленец Е.

Кандидат: имя и число голосов. Операции: зарегистрировать кандидата, отдать голос, лидер, распределение голосов в %, проверка ничьей.

## Файлы

| Файл | Что это |
|------|---------|
| `structural.py` | структурный стиль: данные в словаре, логика в функциях |
| `oop.py` | ООП-стиль: классы `Candidate`, `Election`, `ConsoleApp` |

Язык: Python 3, только стандартная библиотека.

## Запуск

Демо-сценарий:

```bash
python3 structural.py
python3 oop.py
```

Интерактивный режим (команды `add <имя>`, `vote <имя>`, `show`, `exit`):

```bash
python3 structural.py -i
python3 oop.py -i
```

## Демо-сценарий

Оба файла прогоняют один и тот же сценарий и выводят одинаковый результат (отличается только заголовок):

1. Регистрация трёх кандидатов — у всех 0 голосов, ничья.
2. Пять голосов: у Анны и Бориса по 2 — ничья между ними, распределение 40 / 40 / 20 %.
3. Ещё голос за Анну — лидер Анна, 50 / 33,3 / 16,7 %.
4. Ошибки: повторная регистрация и голос за незарегистрированного кандидата.
5. Пустое голосование — лидера нет.

Фрагмент вывода:

```
3. Ещё один голос за Анну
  Всего голосов: 6
  Анна         3 гол.   50.0 %
  Борис        2 гол.   33.3 %
  Вера         1 гол.   16.7 %
  Лидер: Анна
```

## Чем отличаются подходы

| | Структурный | ООП |
|---|-------------|-----|
| Данные | словарь `{имя: голоса}`, передаётся в каждую функцию | спрятаны в объектах: голоса внутри `Candidate`, список кандидатов внутри `Election` |
| Поведение | отдельные функции `register_candidate`, `cast_vote`, `get_leader`, `is_tie`, `distribution_percent` | методы объектов: `Election.register`, `Election.vote`, `Candidate.add_vote` и т.д. |
| Защита данных | словарь можно изменить напрямую, минуя функции | поле `_votes` меняется только через `add_vote()`, снаружи доступно только для чтения |
| Ввод-вывод | функции `run_demo`, `run_interactive` | отдельный класс `ConsoleApp`, логика голосования о консоли не знает |
| Несколько голосований | создаём несколько словарей | создаём несколько объектов `Election` |

Правила одинаковые в обоих вариантах: пустое имя и повторная регистрация дают ошибку, голос за незарегистрированного кандидата — ошибку. Лидер есть, только если максимум голосов у одного кандидата; если у нескольких — это ничья. Если голосов 0, у всех 0 %.
