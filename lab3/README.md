## Что в репозитории

| Файл | Что это |
|------|---------|
| `main.py` | выданный модуль «Голосование» |
| `test_main.py` | юнит-тесты на pytest (29 тестов) |
| `requirements.txt` | зависимости для тестов |

## Установка зависимостей

Нужен Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Как запустить тесты

```bash
pytest -v
```

## Как получить отчёт о покрытии

В консоли, с номерами непокрытых строк:

```bash
pytest --cov=main --cov-report=term-missing
```

HTML-отчёт (появится папка `htmlcov`, открыть `htmlcov/index.html`):

```bash
pytest --cov=main --cov-report=html
```

То же самое через `coverage`:

```bash
coverage run -m pytest
coverage report -m
```

## Что проверяют тесты

| Функция | Обычный случай | Граничные случаи и ошибки |
|---------|----------------|---------------------------|
| `register` | кандидат добавляется с 0 голосов | повторная регистрация даёт `ValueError`, голоса при этом не сбрасываются |
| `vote` | счётчик растёт на 1 | неизвестный кандидат даёт `KeyError` и в словарь не попадает; пустой словарь |
| `leader` | один явный победитель | пустой словарь, один кандидат, ничья, у всех по 0 |
| `distribution_percent` | 3 и 1 голос дают 75 % и 25 % | пустой словарь, 0 голосов всего, сумма равна 100, входной словарь не меняется |
| `is_tie` | два равных лидера | пустой словарь, один кандидат, ничья только внизу таблицы |

Замечание по коду: импорты `List` и `Tuple` в `main.py` не используются. Я их не убирал, потому что модуль нужно было скопировать как есть.
